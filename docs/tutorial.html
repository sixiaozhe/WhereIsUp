WhereIsUp 图解教程

用一个小到能一眼看完的神经网络，把“训练深度学习模型”的绝大部分知识讲一遍：数据、卷积、损失、反向传播、优化器、评估、C 端部署。

17,780 参数 纯 numpy 手写训练 纯 C 推理 单图 ≈ 5 ms 内存 < 4 MB

1任务与自标注

给一张照片，它可能是把某张“正立”照片顺时针旋转了 k·90° 得到的，其中 k ∈ {0,1,2,3}。我们要判断 k，也就是判断“真实的上方”落在显示图的哪一侧，然后把它转回去。

1.1 约定（贯穿全项目）

类别 k含义显示图里“上”在哪侧纠偏方法
0顺时针转 0°上不动
1顺时针转 90°右逆时针转 90°
2顺时针转 180°下逆时针转 180°
3顺时针转 270°左逆时针转 270°

代码里 rotate_cw（顺时针，用 np.rot90(..., -k)）与 correct（逆时针，用 np.rot90(..., k)）互为逆操作，见 src/data.py。

1.2 标签为什么是免费的

picsum.photos 上的原图都被视为“正立”。训练时随机抽一个 k，把照片转 k·90°，旋转角本身就是标签。不用人工标注，同一张源图每个 epoch 还能以不同类别出现——数据量凭空 ×4。

核心思想把“无标签图片”变成一个可以无限生成带标签样本的自监督任务，这正是这个项目适合教学的原因。

2数据切分与数据泄漏

如果先对每张源图生成 4 个旋转版本，再把这些旋转版本随机分到训练集和测试集，那么同一张源图的副本会同时出现在两边。模型只要记住“这张图的纹理”，测试时就能认出它的旋转版本——准确率虚高。这叫数据泄漏。

迁移到别处人脸识别按“人”切、语音按“说话人”切、医疗影像按“病人”切。只要一个样本能派生出多个版本，就在最外层切。

6反向传播

训练就是不断回答：“每个参数往哪个方向调、调多少，才能让损失变小？” 反向传播 = 链式法则的工程化实现。

7优化器

最朴素的更新是 SGD：p ← p − η·g。它方差大、在狭长谷底来回震荡。加动量记住历史方向：

v ← μv − ηg　　p ← p + v　（μ 通常 0.9）

学习率是第一超参太大不收敛甚至发散，太小收敛慢。教程主线用 lr=0.006、60 epoch；可自行试 0.001 与 0.05 观察 data/training_curve.csv 的差异。

9.3 数据策展：数据质量决定上限

随机照片里约一半根本没有上下线索（特写、俯拍、纹理、抽象图），旋转 90° 后依然“看起来合理”。模型对这类图本质无法判断——不是模型不够大，而是信息不在图里。

一个简单可解释的线索是“天空在上”：正立照片顶部通常比底部亮。up_cue = 顶部 16 行平均亮度 − 底部 16 行平均亮度，据此过滤掉歧义图。

12数值对拍与 TTA

把 Python 模型搬到 C，最容易错的不是思想，而是细节：索引顺序、padding 边界、归一化量级、softmax 是否减最大值。这些错误不会让程序崩溃，只会“看起来差不多但就是不对”。

12.1 测试时增强（TTA）

旋转任务有一个天然对称性：把输入顺时针再转 r·90°，真实类别就从 k 变成 (k+r) mod 4。于是对四个视角各前向一次，把第 r 次结果反向平移类别后平均——这就是 TTA。

13进阶路线

方向做法预期收益
int8 量化权重/激活按 s = max|x|/127 定点，卷积用 int32 累加体积 ↓4×，速度更快，精度损失很小
更深的网络加通道/层、BatchNorm、残差连接（配数值梯度校验）表达力更强，但手写反向更易出错
任意角度回归输出连续角度，用 cos/sin 表示以处理周期性从 4 分类走向实用纠偏
完整闭环数据 → 手写训练 → 导出权重 → 纯 C 推理 → 数值对拍。走到这里，你已经把训练一个神经网络所需的绝大部分知识亲手过了一遍。
