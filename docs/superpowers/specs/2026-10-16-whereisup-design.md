- 日期：2026-10-16

## 1. 项目目标

训练并部署一个小型神经网络：输入一张可能被旋转过的照片，判断**图片的"上边"在哪**（即图片被顺时针旋转了 0°/90°/180°/270° 中的哪一个角度），并输出纠正后的图片。

核心诉求：

1. **推理运行环境极简**：权重全部导出为 C 数组，推理程序仅依赖 gcc 与随仓库附带的标准 C 代码（两个单头文件库），不需要任何第三方运行库、Python 或深度学习框架。
2. **教学价值**：训练过程作为向新手教学"神经网络训练绝大部分知识"的完整例子。

## 2. 已确认的需求决策

| 决策点 | 结论 |
|---|---|
| 任务含义 | 判断旋转图片的上边在哪（4 类分类），不是地理位置 |
| 训练数据来源 | 从素材网站下载真实照片：picsum.photos（Unsplash 免版权授权，网络可达性已验证） |
| 训练器实现 | Python3 + numpy 手写前向/反向传播，不使用任何深度学习框架 |
| 推理实现 | 纯 C（-std=c99），float32，权重为 C 数组 |
| C 端功能 | 报告四类概率与"上边在哪"判定 + 用 stb_image_write.h 保存纠正后的 PNG |
| 模型方案 | 方案 A：微型 CNN；纯 MLP 仅作为教程中的对照实验 |

## 4. 数据管线

1. **下载**（`scripts/download.sh`）：遍历 picsum.photos 的照片 id（0–1084 中的有效 id），每个 id 下载一张尺寸较大的原图（≥512px），存入 `data/raw/`。失效 id、下载失败自动跳过并记录清单；校验文件为 JPEG。目标约 2000 张。
2. **在线旋转自标注**：picsum 的源照片均视为"正确朝向"。训练时对每张图在线随机施加顺时针旋转 {0°,90°,180°,270°}，旋转角即类别标签（0/1/2/3）。旋转在更高分辨率图上做，再缩放到 64×64，避免边角信息损失。
3. **切分**：按**源照片**以 8:1:1 随机切分为 train/val/test，固定随机种子保证可复现。同一源照片的旋转版本绝不跨集合（防数据泄漏）。
4. **预处理**：双线性缩放到 64×64 → 按 train 集统计的 per-channel 均值/标准差归一化 → 归一化常数随权重一并导出给 C 端。
5. **数据增强**（仅训练集，在线进行）：水平随机翻转；亮度/对比度小幅抖动。明确禁止垂直翻转（会把标签从"上"变成"下"，属于非法增强，教程中作为重要知识点讲解）。
6. **缓存**：预处理后的数组缓存为 npz，重复训练不解码原图。

## 5. 模型

```
输入 3×64×64
├─ Conv2d: 3→8,  3×3, stride 1, padding 1   → 8×64×64
├─ ReLU
├─ MaxPool2d 2×2                            → 8×32×32
├─ Conv2d: 8→16, 3×3, stride 1, padding 1   → 16×32×32
├─ ReLU
├─ MaxPool2d 2×2                            → 16×16×16
├─ Flatten                                  → 4096
├─ Linear: 4096→4
└─ Softmax（输出 4 类概率）
```

- 参数量：conv1 8×3×3×3+8 = 224；conv2 16×8×3×3+16 = 1,168；fc 4096×4+4 = 16,388；**合计 17,780**，float32 约 69 KB。
- 初始化：He 正态初始化（conv/fc），零偏置。
- 导出格式（`c/weights.h`）：
  - 权重数组 `float w1[224], b1[8], w2[1168], b2[16], w3[16388], b3[4];`
  - 卷积权重排列方式（out-ch, in-ch, kh, kw）以注释明确写出
  - 归一化常数 `NORM_MEAN[3], NORM_STD[3]`
  - 文件头注释写入生成日期与源 npz 的 md5（版本绑定，防权重/代码不匹配）

## 6. 训练器与部署

### 6.1 训练器（src/）

- `nn.py`：
  - 各层前向 + 反向均为手写 numpy 实现；Conv2d 用 im2col 展开实现（兼顾速度与教学可读性）。
  - Softmax 与交叉熵合并为 `SoftmaxCE`，内部使用 log-sum-exp 保证数值稳定；反向梯度 `(prob - onehot) / batch`。
- `train.py`：
  - batch=64；SGD + momentum 0.9；初始 lr=0.01，cosine 衰减到 0；约 10 epochs（以验证集准确率收敛为准，可调）。
  - 每 epoch 计算 train/val 的 loss 与 acc，打印进度；保存验证集最优权重到 `data/best.npz`。
  - 输出 `data/training_curve.csv`（epoch/loss/acc）与混淆矩阵；若装有 matplotlib 则额外画图，没有则只出 CSV。
  - 权重初始化用固定种子，整条链路可复现。
- `infer_py.py`：加载 npz，实现与 C 端完全一致的推理流程（缩放/归一化/前向），用于对拍。

### 6.2 C 推理端（c/）

- CLI：`./whereisup <image> [-o fixed.png]`
  1. stb_image.h 解码 JPEG/PNG/BMP，失败则报错并以非 0 退出码退出。
  2. 双线性缩放到 64×64（与 Python 实现相同的公式），按导出的均值/标准差归一化。
  3. 纯 C 前向：conv → relu → maxpool → conv → relu → maxpool → fc → softmax，全 float32。
  4. 打印判定：四类概率 + "上边在：上/右/下/左；将图片逆时针(顺时针)旋转 X° 即可纠正"。
  5. 以预测角度旋转**原始分辨率**图片，用 stb_image_write.h 保存为 PNG（未指定 `-o` 只报告不写文件）。
- 构建：`make`（gcc，`-std=c99 -O3 -Wall -Wextra`，目标零警告）。
- 依赖：仅 libc + 两个随仓库附带的 stb 单头库（无需安装任何包）。

### 6.3 部署正确性校验

- `check_parity.sh`：随机抽 N=8 张图，分别运行 `infer_py.py` 与 `whereisup`，对比 logits/概率，要求最大绝对差 < 1e-4。通过后才允许汇报正确性。

## 7. 教程文档（docs/TUTORIAL.md 章节规划）

1. 任务定义与数据自标注思想：为什么"旋转"让标注免费
2. 数据集切分与数据泄漏：为什么按源照片切
3. 图像即张量：像素、通道、缩放、归一化
4. 神经网络的积木：卷积/ReLU/池化/全连接/softmax（每个配手算小例子）
5. 损失函数：交叉熵；为什么精确率/准确率不能直接当损失
6. 反向传播：链式法则逐层推导（conv/pool/fc/softmax），与 nn.py 逐行对照
7. 优化器：SGD → 动量 →（延伸 Adam）；学习率为什么是第一个要调的超参；cosine 调度
8. 训练循环：epoch/batch/检查点/验证集选模
9. 过拟合与正则化：数据增强、weight decay、本任务为何禁垂直翻转
10. 评估：混淆矩阵与错误分析
11. 部署：权重导出为 C 数组、前向的 C 实现
12. 端到端检验：Python(CPU)/C 数值对拍的意义与做法
13. 进阶路线：int8 量化、更深网络、真实视频/地标任务延伸（仅讨论，不实现）

## 9. 错误处理

- 下载：单 id 失败跳过并记录；最终不足 2000 张时打印实际数量并继续（训练脚本按实际数量工作）。
- 训练前检查所有源图可被解码，坏图剔除。
- C 端：文件打不开、格式不支持、图片过小（< 8px）→ 明确报错、非 0 退出码，不静默。
- weights.h 与训练产物绑定：npz 变更必须重新导出；对拍脚本同时充当版本回归测试。
